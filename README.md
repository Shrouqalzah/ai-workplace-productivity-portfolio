## Project Overview
This portfolio demonstrates how a Business Analyst can use generative AI to support recurring workplace tasks — requirements gathering, stakeholder communication, meeting-note synthesis, UAT planning, and rollout planning — for a fictional citizen-services product, GovConnect. All AI-assisted outputs were verified against source material and reviewed before being marked complete.

## Selected Workplace Scenario
The selected role is a **Business Analyst** supporting **GovConnect**, a fictional government digital-services portal that lets citizens apply for and track public services online. The role covers requirements gathering from department stakeholders, user story and acceptance criteria drafting, UAT coordination, meeting-note synthesis into decision-ready briefs, stakeholder communication, and rollout planning.

## Course Skills Demonstrated
- Structured prompting using C.A.R.E. and R.C.T.O.
- Professional writing using Draft → Verify → Refine → Human Sign-off
- Extracting, summarizing, restructuring, and prioritizing information from meeting notes
- Planning using Goal → Mechanisms → Phases → Tasks
- Verifying AI-generated content against source material, including catching cross-section inconsistencies
- Applying responsible AI principles and Green/Amber/Red information classification
- Building a realistic personal AI integration plan

## Key Learnings
1. A structured prompt (C.A.R.E./R.C.T.O.) produces far more usable output than a vague request — especially for requirements and UAT work, where ambiguity is costly.
2. AI-generated summaries and briefs can sound confident while still inventing owners, deadlines, or decisions — verifying against the raw source is not optional.
3. Verification isn't just a single-document check — Section 5 caught an inconsistency *between* two sections, which wouldn't have surfaced without deliberately cross-checking.
4. Marking gaps as `[Not Specified]` instead of guessing keeps a document honest and actually more useful for a sponsor making a real decision.
5. Human sign-off has to be a real step, not a formality — several drafts in this portfolio were held back specifically because they hadn't been reviewed yet.
